# Data Link Layer

This project simulates a Data Link Layer communication between a server and a client, demonstrating reliable data transfer with error detection and control mechanisms. The primary focus is on ensuring correct data transmission through appropriate checks and protocols.

## Features

- **Client-Server Communication**: Establishes a reliable communication channel between a server and a client.
- **Error Detection**: Implements error detection mechanisms to ensure data integrity.
- **Flow Control**: Manages data flow to prevent buffer overflow and ensure smooth data transfer.
- **Acknowledgment and Retransmission**: Implements acknowledgment checks and retransmission of lost or corrupted data.
- **Data Validation**: Validates data packets for consistency and correctness.

## Technologies Used

- **Programming Language**: Java
- **Networking Library**: Java Sockets, TCP/UDP protocols
- **Error Detection**: Checksum

## Getting Started

### Prerequisites
